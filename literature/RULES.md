# Rules for Literature Agents

Every literature agent (Claude Code subagent or Codex run) follows these rules. No exceptions.

## 0. Your own files only (agents run in parallel)
Several agents work at the same time. To avoid overwriting each other, **write only to files named after you** (`<agent>` = your name, e.g. `lit-rq1`):

| What | Your file |
|---|---|
| Search log | `literature/search-logs/<agent>.md` (copy `_TEMPLATE.md`) |
| BibTeX | `literature/bib/<agent>.bib` |
| Paywalled PDFs | `literature/to-acquire.d/<agent>.md` (copy `_TEMPLATE.md`) |
| Findings | the findings file named in your assignment |
| PDFs | `literature/pdfs/<bibkey>.pdf` (check it does not exist yet) |

Never edit another agent's files. The merged views (`search-log.md`, `references.bib`, `to-acquire.md`) are generated by `scripts/merge-literature.sh` — do not edit them by hand.

## 1. Search systematically and log everything
- Databases, in this order of preference: IEEE Xplore, ACM Digital Library, Semantic Scholar, arXiv, MDPI / PMC (open access), Google Scholar (for snowballing and grey literature only).
- Useful APIs (no key needed):
  - Semantic Scholar: `https://api.semanticscholar.org/graph/v1/paper/search?query=...&fields=title,authors,year,venue,externalIds,openAccessPdf,citationCount`
  - arXiv: `http://export.arxiv.org/api/query?search_query=all:...`
  - Crossref (verify DOI + metadata): `https://api.crossref.org/works/<DOI>`
  - Unpaywall (find legal open-access PDF): `https://api.unpaywall.org/v2/<DOI>?email=<email from git config user.email>`
- **Log every search** as one row in your search log *at the time you run it*: date, agent, database, exact query string, filters, hits, screened, included, notes.
- Default filters: publication year ≥ 2015 (older only for foundational specs/RFCs), English, peer-reviewed preferred.
- Snowballing (references / citing papers of a key source) counts as a search and is logged too.
- Be polite to APIs: pause ~1 s between Semantic Scholar requests; back off on HTTP 429.

## 2. Find and download full texts (legal sources only)
- For every included source, try to obtain a full-text PDF in this order: `openAccessPdf` from Semantic Scholar → Unpaywall `best_oa_location` → arXiv → publisher open-access page → author/university repository.
- Save to `literature/pdfs/<bibkey>.pdf` and check with `file` that it really is a PDF (not an HTML login page).
- Never use shadow libraries (Sci-Hub, LibGen, etc.).
- No legal open-access copy → add to your `to-acquire.d/<agent>.md`. Felix downloads it via the FH library.

## 3. Extract findings with page numbers
- Extract text page by page: `scripts/pdf-page.sh <pdf> <page>` (PDF page index) or `pdftotext -layout -f N -l N file.pdf -`.
- **Page = the printed page number of the journal/proceedings** (e.g. p. 1234), not the PDF page index. Determine the offset once per PDF from the header/footer and record it in the offset table of your findings file.
- No printed pagination (arXiv preprint, web page, standard): cite by section, e.g. `Sec. 4.2`.
- Evidence quotes: short (one sentence max), verbatim, in quotation marks.
- **Never** write a page number, quote, figure, author or DOI you have not read in the source in this session. If unsure, write `UNVERIFIED` and say why.
- Abstract-only sources may be screened and logged, but their findings are marked `basis: abstract` and get no page number.

## 4. Write findings
- Use `literature/findings/_TEMPLATE.md`.
- Each finding: claim in your own words (English), bibkey, page/section, short quote, basis (full text / abstract), relevance (supports / contradicts / extends / method inspiration).
- Explicitly note **methodological gaps** in related studies — they support the thesis' novelty argument (four metric dimensions in one consistent experiment).
- Material relevant to *another* RQ goes into the "Cross-references" section of your findings file — don't research it yourself.

## 5. References
- Every included source gets an entry in your `bib/<agent>.bib`: DOI verified via Crossref (or `eprint` for arXiv), `url`, and `file = {literature/pdfs/<bibkey>.pdf}` if downloaded.
- Bibkey format: `firstauthorYEARkeyword` (lowercase, ASCII), e.g. `dizdarevic2019survey`.

## 6. Scope discipline
Stay in your assigned topic. Thread/Matter, CoAP, ML: boundary/related-work material only, no deep dives (unless your assignment says otherwise).

## 7. Finish with a short report
Reply with: number of searches, sources screened/included, PDFs downloaded, items added to to-acquire, the 3–5 most important findings, open questions.
